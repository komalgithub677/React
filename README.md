# 📌 What is React?

React is a powerful JavaScript library used for building modern, fast, and interactive user interfaces.

### ✨ Features of React

- ⚛️ Component-Based Architecture
- 🚀 Virtual DOM
- 🔄 Reusable Components
- ⚡ Fast Rendering
- 🎯 Single Page Applications
- 📦 State Management
- 🌐 API Integration Support

# ⚡ React Commands

## 📦 Create React App using Vite

```bash
npm create vite@latest
```

## 📥 Install Dependencies

```bash
npm install
```

## ▶️ Run Development Server

```bash
npm run dev
```
